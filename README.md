# AIN SALAH EXPRESS
منصة توصيل محلية لمدينة عين صالح بواجهة عربية RTL.
## التشغيل
`npm install` ثم `npm run dev`، وفحص الإنتاج عبر `npm run build`.
## Supabase
أنشئ مشروعاً، نفّذ SQL من `001_initial_schema.sql`، ثم ضع URL و anon key في متغيرات البيئة حسب `.env.example`. لا تضع service_role key في الواجهة.
## الحالة
هذه نسخة تطويرية أولية. تسجيل الدخول، التحقق من الهوية، الإدارة الآمنة، توزيع الطلبات، GPS المباشر واختبارات الأمان والنشر ما زالت مطلوبة قبل استقبال طلبات حقيقية.
