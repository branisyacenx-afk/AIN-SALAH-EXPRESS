# تطبيق عين صالح إكسبريس الأصلي (Android)

هذا مجلد تطبيق React Native / Expo مستقل، وليس نسخة WebView من الموقع.

## التقسيم
- حساب الزبون: واجهات هاتف أصلية للمتاجر والمنتجات والسلة والطلبات.
- حساب السائق: واجهات هاتف أصلية للطلبات المسندة وحالة التوصيل ومشاركة GPS أثناء العمل.
- حسابا الإدارة والتاجر لا يفتحان داخل التطبيق؛ يواصلان استخدام لوحة الويب على الكمبيوتر والآيباد.

## الربط
يستخدم التطبيق نفس مشروع Supabase الموجود للموقع، ونفس Auth وبيانات المتاجر والمنتجات والطلبات وجداول المواقع وRealtime وRPC. لا تنشئ قاعدة بيانات جديدة ولا تغيّر مخطط قاعدة البيانات لتشغيل التطبيق.

## إعداد بيئة البناء
انسخ قيم مشروع Supabase الحالي إلى:
- EXPO_PUBLIC_SUPABASE_URL
- EXPO_PUBLIC_SUPABASE_ANON_KEY

يجب أن تكون هذه القيم هي نفسها المستخدمة في Vercel. لا تضع service-role key داخل تطبيق الهاتف مطلقاً.

## البناء محلياً
من هذا المجلد:
- npm install
- npm run typecheck
- npx expo prebuild --platform android
- npx expo run:android

هذه بداية التطبيق الأصلي؛ يجب استكمال واختبار كل تدفقات التطبيق، صلاحيات GPS، الإشعارات، الخرائط، وسلوك الاتصال قبل اعتباره جاهزاً للإطلاق.
